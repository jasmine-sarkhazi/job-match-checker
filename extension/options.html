Job Match Checker

Upload your resume once. Then, on any job page, click the extension and ask Am I a fit for this job? Scoring is done by Jev (TypeSafe AI) using your own API key.

1. TypeSafe API key

Create a key at console.typesafe.ai/keys. It is stored only in this browser's extension storage and sent only to api.typesafe.ai.

2. Your resume

Upload a PDF, .txt, or .md file, or paste the text. Only the extracted text is stored.
